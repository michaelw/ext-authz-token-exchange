# Security Policy

## Supported versions

Security fixes are provided for the latest released version. Older releases are
not maintained; upgrade to the latest release to receive fixes.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/michaelw/ext-authz-token-exchange/security/advisories/new)
to report a suspected vulnerability. Do not open a public issue or pull request
with exploit details. Include the affected version, deployment mode, relevant
configuration, reproduction steps, expected and observed behavior, and
potential impact. Remove tokens, credentials, personal information, and other
sensitive data from the report.

We aim to acknowledge reports within five business days when possible. This is
a best-effort target, not a guaranteed response or remediation deadline. We
coordinate validation, remediation, and disclosure with the reporter, and
credit reporters in advisories unless they prefer otherwise.
